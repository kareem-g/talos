## Implementation Plan: Browser-like Agent Workspace (Right Pane Redesign)

### Overview
Replace the current 5-tab right rail (Git/Plan/Agents/Browser/Terminal) with a browser-like Agent Workspace featuring a floating context-menu HUD, browser-style navigation, and 5 views (Browser, Git Diff, Plan, Agents, Todos).

### Files to Create/Modify

| File | Action | Reason |
|------|--------|--------|
| `session/RightRail.tsx` | **Rewrite** | Transformed into the new workspace shell (HUD + nav + tabs + content + toasts) |
| `session/RightRailViews.tsx` | **New** | 5 content views: BrowserView, GitDiffView, PlanView, AgentsView, TodosView |
| `session/RightRailPopovers.tsx` | **New** | 5 popover components: GitPopover, PlanPopover, AgentsPopover, TodosPopover, MorePopover |
| `session/workspaceData.ts` | **New** | Data adapters: tasksFromConversation, buildTodoList, deriveAgentActivity, etc. |
| `shared/DiffViewer.tsx` | **New** | Upgraded unified diff viewer with line numbers, added/removed counts, file header |
| `components/ui.tsx` | **Modify** | Extract `DropdownList` from TasksAndExecution → shared `DropdownList` component |
| `session/TasksAndExecution.tsx` | **Modify** | Import `DropdownList` from ui.tsx instead of local definition |
| `shared/GitComponents.tsx` | **Modify** | Accept `DiffViewer`-style props or keep as-is; DiffLayer remains for modal overlay use |
| `SessionWorkspace.tsx` | **Minor** | Update `RIGHT_TABS` validation (terminal → todos); pass `onToggleRight` to RightRail so "Close panel" works |

### Implementation Order (18 steps)

#### Phase 1: Foundation — Data Layer + Shared Components
1. **Create `shared/DiffViewer.tsx`** — Unified diff viewer component:
   - Props: `{ path, diff, added, removed, status }`
   - Renders: file header row (path, +N/-N, copy action), line-number gutter, per-line +/- tinting (same tokens as existing DiffLayer)
   - No syntax highlighting (per spec "when supported" — no highlighting lib present)
   - Unified layout, with split layout option at wide widths (future)
   - Accessible: `aria-label` on copy, diff status via `role="status"`

2. **Create `session/workspaceData.ts`** — Data adapters:
   - `tasksFromConversation(sessionId)` — moved from RightRail & TasksAndExecution (exact same logic)
   - `buildTodoList(sessionId)` — wraps `tasksFromConversation` into `TodoItem[]` with `{ id, title, status, priority, assignee, source }`; priority defaults to `medium`, assignee defaults to `session.agent`, source defaults to `plan`
   - `deriveAgentActivity(sessionId)` — walks conversation messages for recent events (tool calls, plan changes, approvals) → `ActivityEvent[]` with `{ timestamp, label, detail, kind }`
   - `useGitBranchSummary(project)` — extracted from current RightRail's `useGitSummary`
   - Types: `TaskStatus`, `TodoItem`, `TodoSort`, `ActivityEvent`, `AgentSummary`

3. **Extract `DropdownList` to `ui.tsx`** — The portal-anchored popover from TasksAndExecution.tsx moves to `components/ui.tsx` as a shared export. TasksAndExecution imports it from there. Tests ensure no behavior change (click-outside/Escape/flip positioning).

#### Phase 2: Rewrite RightRail Shell
4. **Rewrite `RightRail.tsx`** — New scaffold:
   ```
   <div class="flex h-full w-[380px] shrink-0 flex-col bg-canvas">
     <FloatingContextMenu />        ← always visible, HUD
     <BrowserNav />                 ← back/forward/reload + address bar
     <WorkspaceTabs />              ← 5 tabs with badges
     <div class="relative min-h-0 flex-1">
       <div key={tab} class="animate-fade min-h-0 flex-1 flex flex-col">
         {tab === 'browser' && <BrowserView />}
         {tab === 'git' && <GitDiffView />}
         {tab === 'plan' && <PlanView />}
         {tab === 'agents' && <AgentsView />}
         {tab === 'todos' && <TodosView />}
       </div>
       <ToastStack />
     </div>
   </div>
   ```
   - Exports: `RightRail` (same name), `RIGHT_TABS = ['browser', 'git', 'plan', 'agents', 'todos']`, `RightTab`, `TAB_KEY` (unchanged key name)
   - Props interface unchanged from current: `{ session, onOpenSession, onNewTask, tab, onTabChange, notify, onFocusComposer, onFocusSearch }` + new `onToggleRight?: () => void`
   - State: tab (controlled or localStorage-backed), browser nav history stack, toasts
   - Preserves all existing keyboard shortcuts (Ctrl/Cmd+Shift+1..5)
   - Uses design tokens (`bg-canvas`, `bg-surface`, `text-ink`, `border-line`) for the new shell

5. **FloatingContextMenu** (inside RightRail.tsx) — HUD bar:
   - 5 control groups: Git, Plan, Agents, Todos, More
   - Each control: icon + label + live status badge (dot or count)
   - Live data:
     - Git: branch name, `+N −N` diffstat, changed count (from `useGitBranchSummary`)
     - Plan: `done/total` steps (from `tasksFromConversation`)
     - Agents: `N working` count (from `store.sessions` filtered by project + running)
     - Todos: `N remaining` (from `buildTodoList`)
     - More: `Refresh`, `Full-screen`, `Close panel`, `Preferences`
   - Click opens corresponding popover (from RightRailPopovers)
   - Dot colors: green (ok), orange (active/warning), red (blocked/failed)
   - Visual: `bg-surface border-line rounded-xl shadow-overlay` — elevated floating look, compact height (~36px)

6. **BrowserNav** (inside RightRail.tsx) — browser-style navigation:
   - Back/Forward buttons (disabled when history empty) + Reload button
   - Address/workspace field: `dark rounded input bg-field border-line` with icon prefix, placeholder `"URL or workspace path…"`
   - Enter navigates the Browser view to the entered URL
   - Keyboard: Enter to navigate, Escape to clear

7. **WorkspaceTabs** (inside RightRail.tsx) — 5-tab strip:
   - Each tab: icon + label + optional badge (Git: changed count, Agents: running count, Todos: remaining count, Plan: warning)
   - Active state: brighter text + accent underline (bottom border with `border-accent`) + slightly lighter background
   - Horizontal scroll on narrow widths
   - Accessible: `role="tablist"`, `aria-current="page"`, `aria-label` on each

#### Phase 3: Popovers
8. **Create `RightRailPopovers.tsx`** — 5 popover components, each using `DropdownList`:
   - **GitPopover**: branch, status, changed/staged/unstaged counts, actions (View diff, Stage all, Commit, Push, Pull, Create branch, Switch branch, Refresh). Destructive actions (Discard, Force push) disabled with confirmation text.
   - **PlanPopover**: plan title, objective, progress, current step, completed/pending/blocked counts, last updated time, "Open full plan" button
   - **AgentsPopover**: primary agent, active subagents, status, current task, recent activity snippets, "Open Agents view" button
   - **TodosPopover**: remaining/completed/blocked counts, top tasks, "Open Todos view" button
   - **MorePopover**: Refresh workspace, Full-screen mode, Close panel, Preferences (density toggle)
   - All popovers: click-outside + Escape closes, preserve workspace tab, `animate-up rounded-card border-line bg-surface shadow-overlay`

#### Phase 4: The Five Content Views
9. **Create `RightRailViews.tsx`** — All 5 views:

   - **BrowserView**: Centered empty state (globe icon, "No page open", "Enter a URL to browse inline", action button) → iframe when URL entered. Loading spinner while iframe loads. Error state (if sandbox blocks). Reuses iframe pattern from current `RailBrowser`. Supports loading/loaded/error/empty states.

   - **GitDiffView**: Wraps `GitWorkspaceView` (full git workflow: branch selector, commit+push, git graph, changed files). Adds the new `DiffViewer` as the inline diff panel (instead of overlay-only). When a file is selected, shows `DiffViewer` below the file list. On wide width (full-screen mode), side-by-side file list + diff. On narrow, stacked. Header: "Changes" title, branch, changed count, Stage all, Commit actions.

   - **PlanView**: Plan title, objective, overall progress bar, ordered steps. Each step: icon (✓/→/○), title, expandable description, assigned agent, related files. Statuses: completed/in_progress/pending/blocked/failed. Actions: expand/collapse, retry failed step, copy plan, refresh. Reuses `ProgressWidget` pattern but expanded.

   - **AgentsView**: Primary agent card (name, type, status, current task, progress, elapsed time, last activity). Subagents list (from `SubagentsPanel` — same-workspace sessions + providers). Activity stream: derived from `deriveAgentActivity` (conversation events → compact timeline). Statuses: thinking/working/waiting/completed/blocked/failed/paused. Empty state when no agents active.

   - **TodosView**: Summary bar (total, completed, active, blocked, failed). Filter chips: All, Active, Completed, Blocked, By agent, High priority. Sort: Priority, Created, Updated, Agent, Status. Each todo: checkbox, title, status badge, priority chip, assigned agent, source tag, timestamp, related file → open action. Completed tasks muted with strikethrough. Empty state when no todos.

#### Phase 5: Polish
10. **Every state** — loading/empty/error/populated for all 5 views + HUD + popovers
11. **Responsive** — narrow/medium/wide: HUD labels collapse to icons, tabs scroll horizontally, Git view stacks file list above diff, unified diffs, no horizontal overflow
12. **Accessibility** — `aria-label` on all icon-only controls, `title` for unfamiliar icons, `role="tablist"` on tabs, `role="dialog"` on popovers, focus states visible, status not communicated by color alone, keyboard: Escape closes popovers, Tab through the HUD
13. **Interaction feedback** — hover states, focus states, active tab transition, popover animate-up, toast stack for operation results, not distracting

#### Phase 6: Integration & Cleanup
14. **Update `SessionWorkspace.tsx`** — validate `RIGHT_TABS` change (terminal→todos), pass `onToggleRight` to RightRail's More popover "Close panel" action
15. **Remove dead code** — `RightGitPanel.tsx`, `GitToolsCard.tsx`, `WorkspaceSwitcher.tsx` (no imports exist; verify and delete if safe)
16. **Add tests** — `session/workspaceData.test.ts` (unit tests for `tasksFromConversation`, `buildTodoList`, `deriveAgentActivity` — vitest, no DOM needed)
17. **Run full build** — `cd dashboard && npm run build` (tsc + vite) and `npm run lint`
18. **Manual smoke test** — verify the 5 tabs render, HUD shows live data, popovers open/close, keyboard shortcuts work, no regressions in center column
