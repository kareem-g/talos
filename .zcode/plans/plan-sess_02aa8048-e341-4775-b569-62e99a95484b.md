# Phase 13: OpenCode-style Layout Redesign

Goal: Restructure `SessionWorkspace` into a dense, professional agentic IDE layout —
top bar / left sidebar / center chat / always-visible right git panel — while
**preserving** AgentDeck's existing dark theme tokens, UX patterns, chat renderers,
composer, state machine, and all real backend integrations.

The user supplied an exhaustive spec. This plan translates it into concrete
file-level changes. Nothing here invents new backend capabilities — every data
source already exists. We are **rearranging and restyling** what's there.

## Key finding: the components already exist

| Spec element | Already exists in |
|---|---|
| Thought sections (collapsible) | `chat.tsx` → `Reasoning` |
| Tool use w/ timing | `chat.tsx` → `Step` |
| Code/file references + copy/refresh | `chat.tsx` → `Code`, `FileChips`; `Timeline.tsx` action bar |
| `/` and `@` triggers | `Composer.tsx` |
| Full access toggle | `TasksAndExecution.tsx` → `PermissionChip` |
| Model selector | `TasksAndExecution.tsx` → `InlineOptionChip` |
| Git branch selector, diffstat, commit/push, graph | `GitToolsCard.tsx` |
| Changed files w/ diffs | `SessionSidePanels.tsx` → `GitPanel` |
| Project dropdown, branch list, session list, search | `WorkspaceSwitcher.tsx` |
| Session status state machine | `sessionState.ts` + `StateZone.tsx` |
| Live activity + timer | `Timeline.tsx` → `ActivityLine`; `SessionWorkspace` runtime tick |
| Approval flow | `chat.tsx` → `Approval` |
| Terminal tab | `TerminalView.tsx` |
| Session mode (plan/act) data | `events.ts` `mode_changed` → `conversation.mode` |

So this is a **scaffolding + restyle** task. Reuse everything; rearrange the
layout and add thin glue (TopBar, LeftSidebar, RightGitPanel, SessionModeChip).

## File-by-file plan

### 1. New `src/components/desktop/TopBar.tsx` (40px single row)

Extract + restyle the current `SessionWorkspace` header. Left→right:
- `BrandMark` ("AgentDeck") + "New Session" `Button` + current project name
  (mono, truncated) + branch chip (e.g. `feature/ui-changes`).
- Spacer.
- `StatusPill` (Ready/Working/Needs approval…) — reuse existing.
- Monospace runtime timer (the existing `formatRuntime` tick).
- Connection `Dot`.
- Settings `IconButton` (gear). Window-controls placeholder (decorative).

Props: `session`, `uiState`, `runtime`, `connection`, `onNewSession`, `onBack`,
`onOpenSettings`. Reuses `StatusPill`, `Dot`, `IconButton` from `ui.tsx`.

### 2. New `src/components/desktop/LeftSidebar.tsx` (~280px)

Single scrollable column. Top→bottom order per spec:
1. **Project selector dropdown** — lift the workspace-dropdown logic from
   `WorkspaceSwitcher.tsx` (project list w/ counts, check on active, "Inbox"
   for null project).
2. **Active branch + change stats** — current branch name + `+6,034 −708`
   (green/red mono) + "N uncommitted changes". Fetch via `gitApi.branches(project)`
   (already used by `WorkspaceSwitcher.BranchList`). Render inline compact —
   always show current branch + stats (no expand/collapse; the full branch
   list lives in the right panel).
3. **Sessions section** — "+ New task" button at top, then filtered session
   rows (name + relative time + status dot). Reuse `WorkspaceSwitcher`'s
   session-list rendering + `NewSessionLayer` for creation.
4. **Search bar** — session search input pinned above the session list.

Props: `session`, `sessions`, `connection`, `onSelect`, `onNewTask`.

### 3. New `src/components/desktop/RightGitPanel.tsx` (~380px, always visible)

Structure:
- A **~56px vertical icon toolbar** on the left edge (spec: chat, git, files,
  search icons). Active icon highlights. Minimal wiring: `git` is default;
  `chat` focuses the composer; `files` toggles an inline `FilesPanel` (from
  `SessionSidePanels.tsx`) in the panel body; `files`/`search` are graceful
  no-ops if not wired in this pass. Props: `session`, `onFocusComposer`.
- Main panel (fills rest):
  - Header: `GIT · {project-name}` (mono uppercase eyebrow) + refresh.
  - **Branch selector dropdown** — reuse `GitToolsCard`'s branch-menu logic
    (search, checkout, create). Render inline here instead of a modal.
  - Change stats `+6,034 −708` with action icons (commit/push → opens the
    existing `CommitModal`; refresh).
  - `CHANGES · {count}` section header.
  - Scrollable file list: status letter (M/A/D/? colored mono) + full path
    (mono truncate) + `diff` link → opens the existing `DiffLayer` overlay.
    Data from `workspaceApi.overview(project)` → `changed_files` + `diffs`
    (backend already returns per-file diffs; see `workspace.rs:99-119`).
  - Reuse `GitToolsCard` sub-modals: `CommitModal`, `CreateBranchModal`,
    `GitGraphModal`, `DiffLayer`.

Props: `session`, `notify`, `onFocusComposer`.

### 5. New `SessionModeChip` in `TasksAndExecution.tsx`

Add to `ComposerControls` after `PermissionChip`:
- Reads `conversation.mode` (`{ id, modes }`), populated by `mode_changed`
  events (already handled at `events.ts:505`).
- Inline dropdown chip (same `DropdownList` pattern as `InlineOptionChip`).
- Selecting a mode calls `setConfig(sessionId, 'mode', id)`.
- Renders only when `conversation.mode.modes.length > 0`; else hidden.
- Default/placeholder: "plan" / "act" per spec.

### 6. Design tokens — keep as-is

The spec's hex values (`#0d0d0d`, `#4ade80`…) are close to but not identical to
the existing tokens (`--canvas: #09090b`, `--green: #34d399`…). **Keep the
existing tokens** — the spec explicitly says "preserve my current dark UI theme,
color palette". They're already applied consistent. No token changes.

## Out of scope (intentionally)
- New backend endpoints (none needed — `workspace.rs` already returns
  changed_files + diffs + branch + diffstat).
- Mobile layout (separate `SessionView` path untouched).
- Voice, MCP, attachments, message branching (gap-analysis items, not this pass).
- The other `RightRail` tabs (Subagents, Terminals, Browser, Tasks) — their
  content stays reachable from the left sidebar (sessions/new task) and the
  top bar; the right panel becomes Git-dedicated per spec.
