## Goal
Redesign the session-workspace left + right sidebars to match the reference design, fix the git-duplicate and opencode permission-chip-duplicate bugs, make subagents agent-driven, keep colors/functionality, and make it responsive. Web production polish throughout.

## Current architecture (verified)
- `SessionWorkspace.tsx` renders: `TopBar` + `LeftSidebar` (280px) + center (Chat/Terminal) + `RightGitPanel` (380px, `hidden lg:flex`).
- `LeftSidebar.tsx` (280px, always visible): project selector → branch+diffstat row → search → sessions list. **No branch list section.**
- `RightGitPanel.tsx`: 48px rail (Chat/Git/Files/Search) + git view (branch selector w/ search+create+checkout, `GitSummary`, `ChangedFilesSection`, `WorktreeSection`, commit button, `CommitModal`, `GitGraphModal`, `DiffLayer`) + files view (`FilesPanel`). 645 lines, only used by SessionWorkspace.
- `RightRail.tsx`: **dead code** — the exact 6-tab right sidebar the user wants (Sessions/Agents/Terminals/Browser/Tasks/Git), with per-tab panels and `Ctrl+Shift+1..6` shortcuts. Its Git tab currently uses the simpler `GitToolsCard`.
- `ComposerControls` (TasksAndExecution.tsx): `PermissionChip` (icon; reads `permission_mode`), `SessionModeChip` (from `conversation.mode`), `InlineOptionChip` for other config options (already excludes `permission_mode`). **Bug:** for opencode, the config also includes a `mode` option (build/plan) → "mode" renders twice (SessionModeChip + InlineOptionChip).
- Subagents: no frontend protocol for agent-native subagent events yet. `SubagentsPanel` = provider launcher + workspace sessions (manual launch buttons).

## Changes

### 1. Left sidebar — add Git branch section, dedupe (LeftSidebar.tsx)
- Add a scrollable **"Git branch"** section below the session list (matches reference).
- List branches from existing `gitApi.branches(projectPath)`; normalize names (`refs/heads/`, `refs/remotes/origin/`, stray `ref/`/`refs/` prefixes stripped once) and **dedupe by normalized name** (prefer local over `origin/`; current branch wins) — this removes the `ref/ref/…`-style duplicates.
- Current branch: green dot + inline `+added −removed` + "N uncommitted changes"; other branches clickable → `gitApi.checkout` then refresh.
- Remove the old top branch+stats row so the branch name doesn't appear twice.
- Keep existing colors (`#0a0a0c`, zinc), project selector, search, session list, "+ New task", delete-session hover.

### 2. Right sidebar — switch to the 6-tab RightRail (SessionWorkspace.tsx + RightRail.tsx)
- Replace `<RightGitPanel>` with `<RightRail>` in `SessionWorkspace.tsx`.
- Extend `RightRail` props: `notify` (merge toast stack + forward errors to session notices), `onFocusComposer`, `onFocusSearch`; wire searchRef into the Sessions tab (add its search box) and a search icon in the rail.
- **Git tab gets the full workflow** (preserve RightGitPanel functionality): extract RightGitPanel's git content into a reusable `GitWorkspaceView` component (new file `src/components/desktop/session/GitWorkspaceView.tsx`) — branch selector w/ search/create/checkout, `GitSummary`, `ChangedFilesSection` (diff overlay), `WorktreeSection`, commit button + `CommitModal`, `GitGraphModal`, `DiffLayer`. RightRail's Git tab renders it, and keeps the **git/files sub-view toggle** (Files → `FilesPanel`) so the file browser isn't lost.
- Keep the other five tabs as-is (Sessions, Agents→`SubagentsPanel`, Terminals, Browser, Tasks).
- `RightGitPanel.tsx` becomes unused (left in place; import removed).

### 3. Fix opencode permission-mode duplication (TasksAndExecution.tsx)
- In `ComposerControls`, also exclude the `mode` config option from `InlineOptionChip` when `conversation.mode` (SessionModeChip) is rendering — mode then appears exactly once.
- Keep the existing `permission_mode` exclusion (icon `PermissionChip` is the single representation).
- All other dimensions (model, effort, …) keep rendering generically → composer already adapts to any CLI; no hardcoded names added.

### 4. Subagents — agent-driven (SessionSidePanels.tsx)
- Rework `SubagentsPanel` "Launch" section: providers shown as **status** (ready/not_installed/error + transport) with the primary hint "Ask in chat to spawn a subagent — the agent handles it automatically"; remove per-provider "start" launch buttons (per your answer: spawning is the agent's AI job).
- Keep the clickable **"This workspace" sessions** roster (click → switch session) and the provider status dots.
- Composer: **no** manual subagent chip/mention — subagents are spawned by asking in chat (existing `#` conversation mention stays for referencing sessions).

### 5. Responsive — collapsible sidebars (SessionWorkspace.tsx + TopBar.tsx)
- Add `PanelLeft`/`PanelRight` toggle buttons in `TopBar` (right side), defaulting both open; state persisted in localStorage.
- Left sidebar and right rail collapse to nothing when toggled; both remain `hidden` below `lg` (mobile already uses the full-screen `SessionView`). Center chat always fluid.

### 6. Verification
- `cd dashboard && npm run build` (tsc + vite) and `npm run lint`; fix any errors. `npm test` for the store/event tests if time permits.
- Manual check in dev server: opencode session → composer shows one mode/permission chip; left sidebar branch list has no duplicates; right sidebar tabs (incl. Git commit/push/graph + Files sub-view) all work; toggling sidebars keeps the chat usable.
