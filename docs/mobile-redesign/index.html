QAI Mobile · Redesign Proposal

Console

A complete replacement of the mobile UI/UX for QAI — the remote control for AI agents running on your desktop. It wears the desktop’s own dark palette (warm charcoal, parchment ink, soft blue accent) with a new instrument geometry the desktop does not have: new navigation, new surfaces, new components, new screens and new states.

The phone’s job is not to show you a transcript. It is to tell you something needs you and let you resolve it in seconds — so the whole interface is built around that one question and one verb.

Design only — no app code changed
