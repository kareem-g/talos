QAI mobile · redesign for approval

iOS-native redesign — every screen, every feature

Ten static mockups of the whole app, rebuilt as a first-party iOS app: true-black canvas, elevated grouped cards, translucent blurred chrome, the SF-style type ramp, one system blue, traffic-light states, mono reserved for machine text. Functionality is unchanged — every control, state, sheet and flow in the current app appears below; this is a visual + navigation-grammar proposal only. Click any card to walk the screens; tab bars, buttons and rows are wired.

True black canvas Grouped inset cards Translucent header / tab bar SF type ramp iOS blue · #0A84FF Traffic-light states Bottom tab bar Bottom sheets & side panes

Navigation decision — drawer → tab bar

Six destinations don't fit an iOS tab bar, so the redesign replaces the drawer with five tabs — Home, History, Agents, Usage, Config — and folds Browsers into the Agents tab as a segmented control (the drawer already grouped them under “Products”). Nothing is lost: recents → the History tab · API-key copy → Config's machine card · Agent Setup → Agents tab · Documentation → Config › About · device/connection card → Config › Machine and every Home header · New task → the “+” on Home & History. Deep links (qai://…) and notification routing are untouched. If you'd rather keep the drawer or trade a different tab, say so — the screens themselves don't change.
