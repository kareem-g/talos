The one flow that starts work from the phone. A bottom sheet over a dimmed Home: Where (recent projects by use, Inbox, or a typed path resolved on the desktop), then What & how (agent, optional first prompt, model / thought / permissions), with each dimension opening its own picker. Every state of the current NewTaskLayer is kept, including the custom-value fallback when an agent reports no model list.
